# Comments & Discussions

## Overview

HashPost provides a comprehensive comment system that enables rich discussions and threaded conversations while maintaining privacy and community standards.

## What Users Can Do

### Creating Comments

**Join Discussions**
- Comment on any post in accessible subforums
- Express opinions and share knowledge
- Contribute to community conversations

**Threaded Conversations**
- Reply to specific comments to create threads
- Build on others' ideas and perspectives
- Create meaningful discussion chains

**Comment Features**
- Write comments with markdown formatting
- Include links and media when relevant
- Edit your own comments as needed

### Voting on Comments

**Engage with Comments**
- Upvote comments you find valuable or insightful
- Downvote comments that don't contribute
- Remove votes to change your mind

**Vote Impact**
- Votes affect comment visibility and ranking
- High-scoring comments appear more prominently
- Community consensus shapes discussion quality
- **Karma Impact**: Votes contribute to the comment author's karma score

**Vote Tracking**
- See your voting history on comments
- Track how your votes affect comment ranking
- Understand voting patterns in discussions

> **📚 Learn More**: For detailed information about how voting affects karma and reputation, see [Karma System](../karma.md).

### Managing Comments

**Comment Ownership**
- Edit your own comments as needed
- Delete comments you no longer want visible
- Control your comment history

**Comment Moderation**
- Report inappropriate comments
- Help maintain community standards
- Support quality discussions

## Error Handling

### Common Issues

**Authentication Problems**
- Ensure you're logged in before commenting
- Check that your session is still valid
- Verify your pseudonym is active

**Content Issues**
- Comments cannot be empty
- Respect community guidelines
- Avoid spam or repetitive content

**Technical Problems**
- Check your internet connection
- Try refreshing the page
- Contact support if issues persist
